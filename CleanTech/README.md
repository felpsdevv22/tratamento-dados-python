Automação de Tratamento de Dados

Sistema desenvolvido em Python para automatizar limpeza, validação e processamento de arquivos CSV e Excel.

Funcionalidades
Upload de arquivos CSV e Excel
Remoção de registros duplicados
Validação de emails inválidos
Exibição de métricas de processamento
Exportação automática de dados tratados em Excel
Interface web com Streamlit
Tecnologias Utilizadas
Python
Pandas
Streamlit
OpenPyXL
Regex (re)
Como executar o projeto

Clone o repositório:

git clone https://github.com/felpsdevv22/tratamento-dados-python.git

Instale as dependências:

pip install pandas streamlit openpyxl

Execute a aplicação:

streamlit run app.py
Objetivo do Projeto

O objetivo deste projeto é automatizar tarefas de tratamento e limpeza de dados, reduzindo trabalho manual e melhorando a qualidade das informações processadas.
